# תמלול שיחות – אפליקציית Android (Galaxy S24)

אחרי כל שיחת טלפון האפליקציה מתמללת אותה **בעברית, על הטלפון עצמו** (בלי לשלוח את השיחה לשום שרת), שומרת קובץ `.txt` ושולחת התראה "התמלול מוכן".

> **סטטוס:** הקוד נכתב ונבדק חלקית בסביבת ענן, ללא מכשיר Android. הלוגיקה הטהורה (פענוח שמות קבצים, דגימה מחדש, חלוקה לקטעים, פורמט התמלול) מכוסה בבדיקות יחידה, וקוד ה-JNI נבדק מול ה-API של whisper.cpp. **הקוד של האפליקציה עצמה (Kotlin/Compose) והבנייה המלאה עוד לא רצו אף פעם** – ההרצה הראשונה ב-GitHub Actions היא בדיקת הקומפילציה הראשונה. סביר שיידרשו תיקונים קטנים אחרי ההרצה הראשונה.

## איך זה עובד (ולמה בצורה הזו)

אנדרואיד **לא מאפשר לאפליקציה רגילה להאזין לשיחה** או להקליט את הצד השני שלה: גוגל חסמה את זה לאפליקציות צד שלישי. רק אפליקציית הטלפון של Samsung רשאית להקליט שיחות. לכן:

```
שיחה ──► Samsung מקליטה (הקלטה אוטומטית) ──► קובץ ב-Recordings/Call
              │
סיום שיחה ──► האפליקציה מקבלת התראת מערכת "השיחה הסתיימה"
              │
              ▼
   מוצאת את הקובץ החדש ► מפענחת ל-16kHz ► Whisper בעברית (על המכשיר) ► Documents/CallTranscripts/*.txt + התראה
```

**תנאי הכרחי:** האפשרות "הקלטת שיחות" חייבת להתקיים באפליקציית הטלפון של Samsung במכשיר שלך. היא תלויה באזור/מפעיל ולא הצלחתי לאמת אותה עבור ישראל. אם היא לא קיימת, אין לאפליקציה דרך להקליט שיחות רגילות (הקלטה מהמיקרופון בזמן שיחה על רמקול היא האלטרנטיבה היחידה, ואיננה ממומשת כאן).

## התקנה

### 1. להעלות ל-GitHub
צרו repo **פרטי** והעלו אליו את כל תוכן התיקייה, כולל `.github/` ו-`gradlew`. אפשר לבקש מ-Claude לדחוף בסשן חדש שבו ה-repo מחובר.

### 2. לבנות
כל push ל-`main` מפעיל את `Build APK` (לשונית **Actions**): בדיקות יחידה ← בניית ה-APK ← פרסום ב-**Releases → latest**. הבנייה הראשונה לוקחת כמה דקות (מקמפלת את whisper.cpp).

### 3. להתקין בטלפון
פתחו את דף ה-Releases של ה-repo בדפדפן של הטלפון, הורידו `CallTranscriber.apk` והתקינו (יידרש אישור "התקנה ממקורות לא ידועים" לדפדפן). עדכונים מותקנים בדרך כלל מעל הקודם **ושומרים את המודל**, כי כל הבניות חתומות באותו מפתח (ראו "מפתח החתימה" בהמשך).

### 4. הגדרה ראשונה באפליקציה
1. **אשר הרשאות** (התראות, מצב טלפון – כדי לדעת מתי שיחה נגמרה, וקבצי שמע – כדי לקרוא את ההקלטות).
2. **אפשר ריצה ברקע** (ללא הגבלת סוללה). ב-Samsung כדאי גם: הגדרות ← סוללה ← הגבלות שימוש ברקע ← להסיר את האפליקציה מ"אפליקציות בהמתנה/במצב שינה".
3. **טלפון ← ⋮ ← הגדרות ← הקלטת שיחות ← הקלטה אוטומטית ← כל השיחות** (השמות המדויקים משתנים בין גרסאות).
4. **הגדרות ומודל ← הורדת מודל.** מומלץ להתחיל ב-"Whisper large-v3-turbo (q5_0)" (~570MB). עם מודל ivrit.ai הדיוק בעברית טוב יותר אבל הוא גדול (~1.6GB) ואיטי. הורידו גם את מודל ה-VAD הקטן.
5. הפעילו את המתג **תמלול אוטומטי**. רק הקלטות שנוצרו מרגע ההפעלה יתומללו אוטומטית.
6. **בדיקה:** התקשרו למישהו, דברו כמה שניות וסיימו. תוך דקות אמורה להגיע התראה. אם לא, ראו "פתרון בעיות".

## איפה התמלולים
* באפליקציה: רשימה, צפייה, שיתוף, העתקה ומחיקה.
* כקבצי טקסט: **Documents/CallTranscripts/** (נראה ב"הקבצים שלי").

## פרטיות ומשפט
* האודיו והתמלול לא יוצאים מהטלפון. האפליקציה משתמשת באינטרנט רק כדי להוריד את קובצי המודל.
* בישראל, ככל שידוע לי, הקלטת שיחה שאתה צד לה אינה האזנת סתר; ועם זאת שימוש בהקלטה או הפצתה עלולים להפר את חוק הגנת הפרטיות. זה לא ייעוץ משפטי – כדאי לוודא, במיוחד אם יש צד שלישי מעורב או אם התוכן ישותף.
* **מפתח החתימה** נוצר אוטומטית בבנייה הראשונה ונשמר ב-Actions cache הפרטי של הריפו, לא בקוד. GitHub מוחק cache שלא נעשה בו שימוש 7 ימים; אם זה קורה, הבנייה הבאה תיצור מפתח חדש והטלפון ידחה את העדכון ("האפליקציה לא הותקנה"). במקרה כזה מסירים את האפליקציה ומתקינים מחדש (המודל יימחק ויש להוריד אותו שוב).

## מבנה הפרויקט
```
app/src/main/cpp/            גשר JNI ל-whisper.cpp (נמשך אוטומטית בגרסה v1.9.5 בזמן הבנייה)
app/src/main/java/il/calltranscriber/
  core/      לוגיקה טהורה עם בדיקות יחידה: שמות קבצים של Samsung, דגימה מחדש, חלוקה לקטעים, פורמט תמלול
  whisper/   NativeWhisper (JNI), WhisperEngine, AudioDecoder (MediaCodec ← 16kHz מונו)
  data/      הגדרות, מודלים, אחסון תמלולים, איתור הקלטות (MediaStore / תיקייה), התראות
  work/      CallStateReceiver (שיחה הסתיימה) ← TranscribeWorker (WorkManager), ModelDownloadWorker
  ui/        Jetpack Compose, ממשק בעברית מימין לשמאל
.github/workflows/build-apk.yml
```

בנייה מקומית (Android Studio, או `ANDROID_HOME` מוגדר): `./gradlew :app:testDebugUnitTest :app:assembleRelease` – ה-APK ב-`app/build/outputs/apk/release/`. נדרש NDK `27.2.12479018` ו-CMake `3.22.1`.

## רעיונות להמשך
* כיווץ המודל (q5_0) על המכשיר אחרי הורדת מודל f16.
* תמלול לפי דוברים (diarization), חיפוש בתמלולים, סיכום שיחה.
* שינוי ל-`armv8.6-a+i8mm` ב-`CMakeLists.txt` אם מדידה מראה שהוא מזרז (ה-S24 תומך, אבל לא בדקתי).
